# Team Orange

**University of Miami**  
**ITD 410 (Fall) and ITD 420 (Spring), 2026–2027 — Capstone I**

## Project
Ultrasonic directional sound tower capstone (ITD Sound Out). This private repository holds the team’s design files, firmware, electronics, experiments, and project records.

## Repository layout
- `firmware/` — source code, configuration, and programming instructions.
- `cad/` — editable mechanical models, drawings, and manufacturing exports.
- `electronics/` — schematics, PCB layouts, wiring diagrams, and bill of materials.
- `testing/` — test procedures, raw measurements, and results.
- `documentation/` — build plans, requirements, assembly notes, and design decisions.
- `project-management/` — milestones, meeting notes, action items, and risks.
